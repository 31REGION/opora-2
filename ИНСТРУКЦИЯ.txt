ОПОРА 2.0 — ПЕРСОНАЛЬНЫЙ ОФЛАЙН-ДНЕВНИК
19 октября 2026 года

ОБНОВЛЕНИЯ
• Мой день: запись событий с временем (пробуждение, прогулка, дела, эмоции, отдых).
• Питание: приём пищи, название, порция, необязательные ккал, белки, жиры и углеводы.
• Профиль: возраст, рост, вес, цель; простое информационное вычисление ИМТ.
• Спортзал: каждое упражнение, время, подходы, повторения, рабочий вес, длительность,
  субъективная трудность и заметки.
• Redmi Watch 4: ручной ввод дневных шагов, среднего/пульса покоя, времени сна;
  измерения пульса по часам; импорт CSV.
• Итоги: шаги за неделю, регулярность питания, количество упражнений, лучшие
  записанные рабочие веса по названию упражнения.
• Обмен: отчёт за последние 14 дневных записей, включая питание, спорт,
  самочувствие, данные часов, проблемы и индивидуальные параметры;
  получение очередного плана от ChatGPT.
• Резервная копия полного журнала в JSON и восстановление, включая данные версии 1.

КАК УСТАНОВИТЬ НА IPHONE С НУЛЯ
1) Разархивируйте архив ZIP на компьютере.
2) Загрузите содержимое папки в корень репозитория GitHub.
3) GitHub → Settings → Pages → Deploy from a branch → main → /(root).
4) Откройте адрес GitHub Pages (HTTPS) на iPhone в Safari.
5) Нажмите «Поделиться» → «На экран Домой» → «Добавить».
6) Запустите ярлык. После успешного первого открытия приложение кешируется
   и основные функции доступны без интернета. Проверьте в авиарежиме.

ЕСЛИ УЖЕ ПОЛЬЗОВАЛИСЬ ОПОРОЙ 1.0
А) СНАЧАЛА создайте резервную копию через «Обмен» → «Экспорт данных JSON».
Б) Замените все файлы старого сайта новыми в ТОМ ЖЕ репозитории и по ТОМУ ЖЕ URL.
В) На iPhone при подключённом интернете откройте приложение, дождитесь обновления,
   закройте/откройте его снова. Если нужно, обновите страницу.
Г) Данные хранятся по прежнему ключу браузера: при сохранении адреса и данных
   сайта старые записи должны остаться. При ошибке импортируйте JSON из пункта А.
ВНИМАНИЕ: если поменять домен, очистить данные Safari/сайта, перейти в приватный
режим или удалить ярлык с данными, локальные записи могут потеряться.

ВАШ ЕЖЕДНЕВНЫЙ ЦИКЛ
Утро: «Мой день» → «Проснулся» → «Самочувствие»; в дневнике время сна и энергия.
Завтрак: «Спорт/еда» → «Питание» → сохранить.
День: «Мой день» → «Прогулка» или «Дело»; тренировки в «Спорт/еда».
Часы: после синхронизации с телефоном переписать показатели в «Спорт/еда»
      или загрузить CSV подготовленного формата.
Вечер: «Мой день» → описание настроения и выполненных дел →
       «Обмен» → «Скопировать отчёт» → отправить в чат ChatGPT.
В чате получить разбор, затем в «Обмен» вставить новые строки плана:
      Утро | Короткая прогулка
      День | 15 минут на резюме
      19:00 | Записать тревожные мысли
Нажать «Применить новый план».

REDMI WATCH 4 И APPLE HEALTH (ЗДОРОВЬЕ)
1) Redmi Watch 4 соединены с iPhone через Mi Fitness.
2) В Mi Fitness откройте Профиль → Сторонние данные → Health / Здоровье.
   Разрешите передачу доступных показателей.
3) В Apple «Здоровье» откройте профиль → Приложения → Mi Fitness,
   включите разрешения на доступные категории.
4) Проверьте, приходят ли шаги, пульс и сон; поддерживаемые категории
   и доступность могут зависеть от версии Mi Fitness, iOS и разрешений.
5) В ОПОРЕ 2.0 автоматического доступа к Apple Health НЕТ: обычное
   веб-приложение PWA не может вызывать HealthKit iOS.
   Для автоматического чтения понадобится разработка отдельного
   нативного iOS-приложения с HealthKit и отдельными разрешениями пользователя.
6) Сейчас можно вручную перенести данные или импортировать подготовленный CSV.
   Экспорт Apple Health ZIP/XML или Mi Fitness напрямую НЕ читается;
   это не заявлено как поддерживаемый CSV.

ШАБЛОНЫ CSV (UTF-8)
Для данных за день:
date,steps,avg_hr,resting_hr,sleep_hours
2026-10-19,6300,78,64,7.1
Для измерений пульса:
date,time,hr
2026-10-19,08:15,71
2026-10-19,12:30,92

Значения в примерах вымышленные, служат только для объяснения формата.
Вставляйте собственные данные. Можно использовать разделитель «;» вместо «,»,
если экспортируете CSV из локализованного Excel. Максимум 500 КБ файла,
до 366 строк дневных данных или до 2500 измерений пульса.
Импорт не отправляет CSV на сервер.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
• Из-за отсутствия базы продуктов приложение не угадывает калории и БЖУ.
  Пустые значения не приравниваются к нулю при аналитическом выводе.
• «Лучший рабочий вес» — максимальный записанный вес, без сравнения
  техники, числа повторений и оценочного 1ПМ.
• Не используйте данные часов/ИМТ для постановки диагноза.
• «Опора» не ставит медицинских диагнозов и не составляет лечебные диеты.
  При длительной апатии, усталости и бессоннице обратитесь к врачу.
• Данные хранятся локально через localStorage. Есть риск потери после очистки
  данных сайта/при нехватке памяти; регулярно экспортируйте JSON.
• Публикация кода на GitHub Pages не публикует содержимое вашего дневника.
  Отчёт попадает в ChatGPT только после отправки вами.
• Персональный анализ ChatGPT требует интернета; офлайн доступны ввод и просмотр.
• Telegram-бот не может обеспечить такой же полностью автономный режим.

ПРОВЕРКА НА КОМПЬЮТЕРЕ
Положите файлы в одну папку. В PowerShell из папки:
    py -m http.server 8000
Откройте http://localhost:8000. Для установки PWA на iPhone нужен HTTPS.
